# Packet Tracer Lab File

This folder contains the completed Cisco Packet Tracer activity for Day 3.

## File

| File | Purpose |
|---|---|
| `day-03-secure-device-management-and-ssh.pkt` | Complete topology, addressing, device configuration and saved lab state |

## Opening the Lab

1. Install Cisco Packet Tracer 9.0.1.0858 or a compatible newer release.
2. Open `day-03-secure-device-management-and-ssh.pkt`.
3. Allow the links to become green before testing.
4. Use ADMIN-PC to repeat the ping and SSH tests in the root documentation.
5. Switch to Simulation mode to inspect ICMP and SSH events.

## Important Security Note

The file is an isolated training lab and may contain disposable lab credentials. Never reuse those credentials on a real device, account or production network.
