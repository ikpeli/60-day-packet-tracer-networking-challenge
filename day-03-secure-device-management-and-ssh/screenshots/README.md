# Screenshot Evidence

This directory contains the public-safe visual evidence for the Day 3 lab. Images are numbered in the order a reviewer should follow them and divided into seven technical sections.

| Folder | Purpose | Images |
|---|---|---:|
| `01-topology` | Physical/logical layout and addressing | 1 |
| `02-router-and-routing` | Router interface and route verification | 2 |
| `03-connectivity-and-ssh` | Successful ping and SSH testing | 7 |
| `04-default-gateway-troubleshooting` | Missing-gateway fault and recovery | 4 |
| `05-telnet-troubleshooting` | VTY transport fault and SSH-only repair | 3 |
| `06-icmp-simulation` | ICMP request/reply packet path | 7 |
| `07-ssh-simulation` | SSH and TCP destination port 22 | 2 |

The full description of every image is in [`../documentation/screenshot-index.md`](../documentation/screenshot-index.md).

Two source images containing reversible Type 7 password strings were intentionally excluded from the GitHub package. Sanitized text configurations preserve the useful configuration detail without publishing those values.
