## Upload Order on GitHub

1. Open the challenge repository.
2. Select **Add file → Upload files**.
3. Drag the complete Day 3 folder into the upload area.
4. Confirm that the subfolders remain intact.
5. Use a commit message such as `Add Day 3 secure device management and SSH lab`.
6. Commit to the appropriate branch according to your normal repository workflow.

The root README uses relative links, so its images and documentation will render correctly when the entire structure is uploaded together.
