Day 3/60 — Packet Tracer Network Engineering Challenge

Today, I implemented secure remote management across two IPv4 networks using a Cisco 2911 router and two Cisco 2960 switches.

I configured management VLANs and SVIs, enabled local authentication and SSH version 2, generated RSA keys, and restricted remote access to SSH only.

I also introduced two controlled faults: a missing switch default gateway and an incorrect VTY transport setting. I isolated each problem using connectivity and configuration evidence before restoring secure access.

Using Packet Tracer's Simulation mode, I examined the ICMP request-and-reply path and confirmed that SSH traffic reached the remote switch on TCP port 22.

My approach throughout this challenge remains simple: build, break, investigate and verify.
