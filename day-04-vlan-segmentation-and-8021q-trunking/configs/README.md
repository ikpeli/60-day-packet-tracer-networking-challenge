# Switch Configurations

This folder contains the reusable core configuration for both Cisco 2960 access switches.

- `sw1-access-config.txt` configures STAFF-PC1, GUEST-PC1, ADMIN-PC, the VLAN 99 management SVI and the trunk to SW2.
- `sw2-access-config.txt` configures STAFF-PC2, GUEST-PC2, the VLAN 99 management SVI and the trunk to SW1.

The files focus on the commands relevant to this lab. Replace `<LAB_PASSWORD>` with a lab-only password before applying the SSH section.
